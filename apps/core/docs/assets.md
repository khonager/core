# Asset provenance

The catalog uses the user's own project artwork where it exists. These assets
were copied from sibling repositories in the shared workspace or from the
owner's GitHub repositories:

- `trans.png`: `Trans/android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png`
- `typesync.png`: `TypeSync/android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png`
- `majika.png`: `Majika/android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png`
- `core.png`: `apps/core/web/icon.svg`, rasterized for Flutter.
- `riverfold.png`: `Riverfold/RiverfoldPrototype/assets/icon.png`.
- `tipstroke.png`: `TipStroke/design/tipstroke-logo-concept.png`.
- `motomeru.png`: `Motomeru/docs/public/icon.png`.
- `files.png`, `wisec.png`, `safezone.png`: each brand's
  `brands/<brand>/public/assets/icons/web-app-manifest-192x192.png` in
  `khonager/files`.
- `website.png`: `portofolio/assets/icons/apple-touch-icon.png`.

The following projects currently ship starter icons or have no final icon.
Core uses distinct provisional marks for them, with editable SVG sources in
[`icon-sources`](icon-sources): Dreamcord (dream orb), Trace (chat bubbles),
Gram (sword), AdWise (ad card), Karma Tracker (heart/clover), and ROID (paired
circles and heart). Replace the provisional artwork in the catalog when each
project adopts a final mark.

Core's temporary ring launcher/web icon is authored as vector geometry in this
repository. No Obtainium artwork has been copied.
