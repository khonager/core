# Asset provenance

The catalog uses the user's own project launcher assets, copied from sibling
repositories in the shared workspace:

- `trans.png`: `Trans/android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png`
- `typesync.png`: `TypeSync/android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png`
- `majika.png`: `Majika/android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png`

Trace currently has a starter Flutter launcher; Core uses a neutral initial
instead. The website uses a standard Material language icon. Replace these via
the catalog when final app artwork is available.

Core's temporary ring launcher/web icon is authored as vector geometry in this
repository. No Obtainium code or third-party raster artwork has been copied.
